Game Boy Overlays for RetroArch.

Hand made and inspired by the original Game Boy DMG using Material Design colors, with simple shapes, minimalist design and high quality textures, keeping in mind comfort, accesibility and good visual proportions.
Supports any phone with FHD+ screens with 18:9 up to 21:9 aspect ratio [1080x2160 up to 1080x2520].

- 7 different skins, Cool Blue, Deep Black, Gorgeous Green, Off White, Radiant Red, Traditional White and Vibrant Yellow.
- Portait and Lanscape support with automatic rotation.
- Fully animated button presses.
- Easy acccess to quick actions on overlay, Open Menu, Fast Forward, *Slow Motion, *Rewind, Screenshot and *Quick Save / *Quick Load.

** Rewind needs to be enabled first to work. Some quick actions will be disabled if playing with RetroAchievement.**

Reccommended Settings:

- Integer Scale: ON, otherwise the content screen will not fit correctly in the overlay.
- Overlay Opacity: 1.0, this overlay doesnt need transparency.
- Autoload Preffered Overlay: OFF, avoids RetroArch loading the default Overlay.
- Show Inputs on Overlay: Physical (Controller), useful for visual feedback showing button presses when playing with physical a controller.
- Save Core Overrides, useful to save and auto apply this settings and overlay to a specific core.
- Every other setting should be ok in its default state.
